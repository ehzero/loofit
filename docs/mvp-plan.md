# Loofit MVP 기획서

작성일: 2026-07-09
상태: MVP 검토본

## 1. 제품 정의

Loofit은 사용자의 분할 루틴을 기억하고, 다음 운동 부위를 자동으로 알려주는 가벼운 운동 기록 앱이다.

사용자는 세트, 중량, 반복 횟수를 기록하지 않는다. 운동 시작과 종료만으로 운동 시간과 운동 부위를 기록한다.

## 2. 제품 한 줄 문구

내 분할 루틴대로, 오늘 할 운동을 바로 시작하세요.

## 3. 핵심 가치

- 오늘 뭐 할지 고민하지 않는다.
- 운동 시작과 종료가 빠르다.
- 내 운동 기록을 한눈에 확인한다.

## 4. 타깃 사용자

- 헬스는 꾸준히 하지만 자세한 기록은 귀찮은 사람
- 세트, 중량 기록 앱을 쓰다 포기한 사람
- 분할 루틴대로 운동하지만 매번 기록하기 귀찮은 사람
- 운동 여부와 운동 시간을 가볍게 남기고 싶은 사람

## 5. 제품 원칙

- 루틴 추천은 AI가 아니라 사용자가 설정한 순서 기반으로 동작한다.
- MVP에서는 세트, 중량, 반복 횟수, 운동 종목 DB를 다루지 않는다.
- 운동 기록의 최소 단위는 "운동 부위 + 시작 시간 + 종료 시간"이다.
- 사용자가 추천 운동을 그대로 시작할 수 있어야 한다.
- 사용자가 추천과 다른 운동을 선택할 수 있어야 한다.
- 기록은 로컬 우선 구조로 저장한다.
- 위젯과 Live Activity는 운동 중 상태 확인과 빠른 종료에 집중한다.

## 6. 핵심 기능

### 6.1 커스텀 운동 부위

사용자가 직접 운동 부위를 만들고 수정할 수 있다.

기본 제공 부위:

- 가슴
- 등
- 하체
- 어깨
- 팔
- 유산소
- 상체
- 푸시
- 풀
- 코어
- 기타

기본 부위는 초기값일 뿐이며, 사용자는 자유롭게 이름을 수정하거나 삭제할 수 있다.

### 6.2 분할 루틴 설정

사용자는 자신의 운동 분할을 설정한다.

예시 1: 3분할

- Day 1: 가슴 + 삼두
- Day 2: 등 + 이두
- Day 3: 하체 + 어깨

예시 2: PPL

- Push: 가슴 + 어깨 + 삼두
- Pull: 등 + 이두
- Legs: 하체

루틴은 여러 개의 루틴 데이로 구성되며, 각 루틴 데이는 하나 이상의 운동 부위를 가진다.

### 6.3 다음 운동 자동 추천

앱은 마지막 완료 운동 기록을 기준으로 다음 운동을 추천한다.

예시:

- 마지막 운동: 가슴 + 삼두
- 오늘 추천: 등 + 이두

추천 규칙:

- 루틴 진행 기준은 날짜가 아니라 완료된 운동 세션이다.
- 완료된 세션이 활성 루틴의 특정 루틴 데이에 연결되어 있으면 루틴이 다음 순서로 진행된다.
- 추천과 다른 루틴 데이를 선택해 완료해도 루틴 완료로 처리하고 다음 순서로 진행한다.
- 정해진 루틴 밖에서 사용자가 직접 만든 자유 운동은 기록만 남기고 루틴 진행에는 반영하지 않는다.
- 유산소, 기타도 루틴 데이에 포함되어 있으면 다른 루틴 데이와 동일하게 루틴으로 처리한다.
- 하루에 여러 개의 루틴 세션을 완료하면 완료 횟수만큼 루틴이 진행된다.
- 운동 취소 세션도 기록으로 남긴다.
- 취소 세션은 히트맵과 대시보드에서는 별도 상태로 표시할 수 있으나, 루틴 진행에는 반영하지 않는다.
- 운동 시간과 관계없이 종료된 세션은 기록으로 저장한다.
- 루틴 마지막 날을 완료하면 다시 첫 번째 루틴 데이로 순환한다.
- 루틴 구성과 순서는 사용자가 루틴 설정에서 직접 변경하기 전까지 자동으로 바뀌지 않는다.
- 루틴 수정 후 다음 추천 시작점은 사용자가 직접 선택한다.
- 운동 기록 수정/삭제는 다음 추천을 자동 재계산하지 않는다. 추천이 잘못되었다면 사용자가 루틴 설정에서 직접 조정한다.

### 6.4 운동 시작과 종료

사용자는 추천된 운동을 바로 시작할 수 있다.

주요 액션:

- 운동 시작
- 다른 운동 선택
- 운동 종료
- 운동 취소
- 운동 변경

운동 종료 시 저장되는 정보:

- 시작 시간
- 종료 시간
- 총 운동 시간
- 운동 부위 스냅샷
- 연결된 루틴 데이
- 메모, 선택 사항

운동 취소도 기록으로 남긴다. 취소된 기록은 루틴 진행에는 반영하지 않으며, 사용자가 기록 상세에서 수정하거나 삭제할 수 있다.

과거 기록은 스냅샷으로 저장한다. 루틴이나 운동 부위 이름을 나중에 수정하더라도 과거 기록의 표시 내용은 당시 기준으로 유지한다.

### 6.5 운동 중 화면

운동 중에는 앱 내부 화면에서 상태를 확인하고 세션을 조작할 수 있다.

표시 정보:

- 운동 중 상태
- 현재 운동 부위
- 경과 시간

필수 액션:

- 운동 종료
- 운동 취소
- 운동 변경

운동 변경은 같은 세션의 최종 운동 대상을 바꾸는 기능이다. 경과 시간은 유지하고, 종료 시점의 최종 운동 기준으로 기록한다.

앱을 종료하거나 백그라운드로 보내도 active 세션은 유지한다. 앱을 다시 열면 운동 중 상태를 복구한다.

### 6.6 위젯

MVP 위젯은 두 가지 타입으로 제공한다.

#### 위젯 1: 운동 시작/종료

운동 실행을 빠르게 하기 위한 위젯이다.

상태별 동작:

- 운동 전: 오늘 추천 운동 표시, 추천 운동 바로 시작
- 운동 중: 현재 운동 부위 표시, 경과 시간 표시, 운동 종료
- 운동 종료 후: 완료 상태 표시, 완료한 운동과 운동 시간 표시

운동 종료 후 위젯 1은 당일 자정까지 완료 상태를 표시한다. 다음 날이 되면 다시 다음 추천 운동 시작 상태로 돌아간다.

위젯 1에서는 다른 운동 선택, 자유 운동 선택, 루틴 수정, 기록 수정은 제공하지 않는다. 세밀한 조작은 앱 안에서만 수행한다.

#### 위젯 2: 히트맵 캘린더

운동 기록을 빠르게 확인하기 위한 위젯이다.

표시 타입:

- 7일 히트맵
- 30일 히트맵

작은 위젯은 7일 히트맵을 우선하고, 중간 또는 큰 위젯은 30일 히트맵을 우선한다.

iOS에서는 홈 화면 위젯과 Live Activity 경험을 우선 검증한다. Android 위젯과 고정 알림은 iOS MVP 반응 확인 후 확장한다.

### 6.7 운동 히트맵

운동 기록을 7일, 30일 단위로 보여준다.

색상 기준은 운동 시간으로 단순화한다.

- 운동 안 함: 빈 칸
- 30분 미만: 약한 색
- 30분 이상 60분 미만: 중간 색
- 60분 이상 90분 미만: 진한 색
- 90분 이상: 가장 진한 색

하루에 여러 번 운동한 경우에는 해당 날짜의 총 운동 시간을 합산한다.

### 6.8 운동 기록 대시보드

앱에서는 위젯보다 더 자세한 운동 기록 대시보드를 제공한다.

구성:

- 7일 히트맵
- 30일 히트맵
- 이번 주 운동 횟수
- 총 운동 시간
- 부위별 운동 시간
- 최근 운동 기록

### 6.9 메인 화면

메인 화면은 내 운동 상태를 한눈에 보여준다.

구성:

- 오늘 추천 운동
- 운동 시작 버튼
- 다른 루틴 운동 선택
- 루틴 밖 자유 운동 선택
- 이번 주 운동 횟수
- 총 운동 시간
- 7일/30일 히트맵
- 부위별 운동 시간
- 최근 운동 기록

제외 기능:

- 중량 기록

## 9. 최종 MVP 정의

사용자가 자신의 분할 루틴을 설정하면 앱이 다음 운동을 추천하고, 사용자는 앱 또는 위젯에서 운동을 시작/종료하며, 앱에서는 자유 운동과 기록 관리를 수행하고, 기록은 7일/30일 히트맵과 대시보드로 쌓이는 앱.

## 10. 기술 스택

### App

- React Native + Expo
- TypeScript
- Expo Router

빠른 MVP 개발과 iOS/Android 확장을 고려해 React Native 기반으로 개발한다.

Expo Go만으로는 위젯, Live Activity, 커스텀 네이티브 기능 테스트가 어렵기 때문에 실제 네이티브 기능 검증은 Expo Development Build를 사용한다.

### State / Storage

- Zustand
- expo-sqlite

운동 세션, 루틴, 운동 부위, 히트맵 데이터는 로컬 DB에 저장한다.

권장 역할 분리:

- SQLite: 영속 데이터의 원천
- Zustand: 현재 운동 세션과 화면 상태 캐시

MVP에서는 로그인과 서버 동기화 없이 Local-first 구조로 시작한다.

### Widget / Native Features

- iOS Live Activities
- iOS Widget
- iOS Home Screen Widget
- Android App Widget
- Android Foreground Notification
- Expo Notifications

iOS 운동 중 상태는 Live Activity와 위젯으로 제공한다.

Android 운동 중 상태는 iOS MVP 반응 확인 후 앱 위젯과 고정 알림 형태로 확장한다. 실제 구현 전 Foreground Service 요건을 별도로 검증한다.

### Build / Deploy

- EAS Build
- EAS Submit
- App Store Connect
- Google Play Console

초기 MVP는 iOS 우선으로 개발하고, 반응 확인 후 Android를 확장한다.

### Backend

MVP에서는 백엔드를 사용하지 않는다.

초기 버전은 서버 없이 로컬 기록만 제공한다. 추후 백업, 기기 간 동기화, 계정 기능이 필요해지면 Supabase 또는 Firebase를 검토한다.

## 13. 성공 기준

- 사용자가 첫 루틴 설정을 완료하는가
- 사용자가 첫 운동 기록을 완료하는가
- 첫 운동 시작 후 종료 완료율이 충분한가
- 7일 안에 두 번째 운동을 기록하는가
- 30일 동안 반복해서 기록하는가
- 히트맵을 다시 확인하는가
- Live Activity 또는 알림에서 운동 상태를 확인하는가
- Live Activity 또는 알림에서 운동을 종료하는가

초기 핵심 지표:

- 루틴 생성 완료율
- 첫 운동 시작률
- 첫 운동 종료 완료율
- 7일 내 두 번째 운동 기록률
- 30일 내 5회 이상 기록률
- 히트맵 재방문율

## 14. 기술 리스크

### iOS Live Activity

Expo의 iOS 위젯/Live Activity 기능은 Development Build가 필요하다. Expo Go에서는 사용할 수 없다.

### Android Foreground Notification

운동 중 고정 알림은 일반 알림보다 Foreground Service에 가깝다.

Android 14 이상에서는 foreground service type 선언과 Play Console 제출 요건이 필요할 수 있다. Android는 iOS MVP 반응 확인 후 확장한다.

### 로컬 데이터 정합성

루틴, 운동 부위, 과거 기록이 서로 영향을 주지 않도록 기록 저장 시 운동 부위 스냅샷을 남긴다.

### 추천 예외 정책

추천 로직은 단순하게 시작하되, 아래 정책을 명시적으로 처리해야 한다.

- 추천과 다른 루틴 데이를 선택해 완료하면 루틴이 진행된다.
- 루틴 밖 자유 운동은 기록만 남기고 루틴 진행에는 반영하지 않는다.
- 유산소, 기타도 루틴 데이에 포함되어 있으면 루틴으로 처리한다.
- 하루에 여러 개의 루틴 세션을 완료하면 완료 횟수만큼 루틴이 진행된다.
- 운동 취소 세션도 기록으로 남기되, 루틴 진행에는 반영하지 않는다.
- 운동 시간과 관계없이 종료된 세션은 기록으로 저장한다.
- 루틴 구성과 순서는 사용자가 직접 루틴 설정을 변경하기 전까지 자동으로 바뀌지 않는다.
- 루틴 수정 후 다음 추천 시작점은 사용자가 직접 선택한다.
- 운동 기록 수정/삭제는 다음 추천을 자동 재계산하지 않는다.
- 운동 중 변경은 같은 세션의 최종 운동 대상을 바꾸며, 경과 시간은 유지한다.
- 앱을 다시 열었을 때 active 세션이 있으면 운동 중 상태를 복구한다.
- 장시간 방치된 active 세션도 자동 종료하거나 자동 삭제하지 않고 그대로 유지한다.
- 과거 기록은 저장 시점의 운동 부위 스냅샷으로 표시한다.

## 16. 첫 번째 마일스톤

목표: 앱 내부에서 루틴을 만들고, 추천 운동을 시작/종료하고, 기록이 히트맵에 반영되는 흐름을 완성한다.

완료 조건:

- 기본 운동 부위가 생성된다.
- 사용자가 루틴을 생성한다.
- 메인 화면에서 다음 운동이 추천된다.
- 추천 운동, 다른 루틴 운동, 자유 운동을 시작할 수 있다.
- 운동 시작 후 운동 중 화면으로 진입한다.
- 앱을 다시 열어도 active 세션이 복구된다.
- 운동 종료 시 기록이 저장된다.
- 운동 취소 시 취소 기록이 저장된다.
- 7일/30일 히트맵에 기록이 반영된다.
- 운동 기록 대시보드에 기록이 반영된다.
- 최근 운동 기록에서 상세 내용을 확인할 수 있다.
